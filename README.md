# Galaxy S/A/Z Series Live Wallpapers Port — Universal Android Support

Brought to you by the community! This repo is a collection of **ported official Live Wallpapers** extracted from Samsung Galaxy series devices (S, A and Z series). Fully tested and working smoothly across **all Android devices** — no Samsung device or specific One UI year restriction required.

Give your home and lock screen that clean Samsung flagship animation feel, on any phone. 🚀

## ✨ Features

- 📱 Works on **any Android phone**, any brand, any model
- 🎞️ Official Samsung Live Wallpapers, ported and repackaged as standalone APKs
- ⚡ Fully tested, smooth performance, no lag
- 🆓 Free and open for everyone
- 🤝 Community-driven — new ports are added over time

## ✅ Compatibility & Prerequisites

| Requirement | Details |
|---|---|
| **Device** | Any Android smartphone (no brand/model restriction) |
| **Android version** | Modern Android versions supported |
| **Required app** | [Wallpapers](https://play.google.com/store/apps/details?id=com.google.android.apps.wallpaper) by Google, from the Play Store (needed to access and apply the Live Wallpaper packages) |

## 📥 Download

Grab the APK of the wallpaper you want from the [Releases](../../releases) section of this repository.

## 🛠️ How to Install & Apply

1. Download and install the APK of the desired Live Wallpaper package from the [Releases](../../releases) page.
2. Open the **Wallpapers** app (by Google) from your app drawer.
3. Scroll down and tap **Live Wallpapers**.
4. Select the newly installed wallpaper, preview it, and tap **Set Wallpaper**.
5. Enjoy your new animated background! 🚀

> **Note:** You may need to allow installation from unknown sources / third-party APKs in your device settings to install the APK files manually.
